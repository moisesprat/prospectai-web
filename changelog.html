Changelog

What's shipped in ProspectAI — the multi-agent brain behind this system (Market Analyst → Technical Analyst → Fundamental Analyst → Draft Strategist → Critic → Final Strategist) and the web frontend that drives it. Newest first.

2026-10-31
ProspectAI Module

v1.11.0

  • Every number and grade in a report is now computed from live data. The AI model only writes the commentary and chooses each stock's action.
  • Stocks whose fundamentals can't be graded are marked unavailable and can only be Monitor or Avoid.
  • A slow Reddit lookup no longer stalls a run.
  • The technical score and overall fundamental grade fields were removed from reports.
2026-10-30
ProspectAI Module

v1.10.1

  • Fixed an issue where the market, technical and fundamental analysis steps could skip fetching live data and answer from the model alone. They now always fetch their data first.
2026-10-30
ProspectAI Module

v1.10.0

  • Analyses now run on Claude Haiku 5.5, Anthropic's latest model.
  • If a data-gathering step finishes without actually fetching its data, the analysis now stops with a clear error instead of reporting figures the model made up.
2026-10-27
ProspectAI Module

v1.9.4

  • Fixed an issue in 1.9.3 where every analysis failed right after starting, caused by an incompatible version of the AI provider's library.
  • Added an automatic check that stops an incompatible AI library version from ever being released again.
2026-10-27
ProspectAI Module

v1.9.3

  • Every analysis now records how long each step and each data source takes, so slow runs can be diagnosed and sped up. The timings appear in a collapsible section of the report's execution metrics.
  • If an analysis fails partway through, the timings gathered up to that point are kept with the error instead of being lost.
  • The AI model for each run is now passed to that run directly, so one run can no longer change another's model settings.
  • Dependencies are locked to exact versions, and every change must pass the full test suite before it can be merged.
  • Releases now go through a single verified process, and the live service reports exactly which version it is running.
