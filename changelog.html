Changelog

What's shipped in ProspectAI — the multi-agent brain behind this system (Market Analyst → Technical Analyst → Fundamental Analyst → Draft Strategist → Critic → Final Strategist) and the web frontend that drives it. Newest first.

2026-11-01
ProspectAI Module

v1.12.0

  • The draft, review and final steps of every analysis now run on Claude Sonnet 5.5, a stronger model than before. The research steps that gather market, technical and fundamental data stay on the faster Claude Haiku 5.5.
  • Reports are still built the same way: every number is computed from live data, and the model only writes the commentary and chooses each stock's action.
2026-11-01
ProspectAI Module

v1.11.1

  • The market research step now runs three web searches instead of one, and a stock is kept only if its ticker symbol actually appears in the search results, so a report can no longer feature a stock the research never mentioned.
  • Each analysis now keeps a short record of the search results its stock picks came from, so a recommendation can be traced back to its sources.
  • Ordinary words and one-letter tickers are no longer counted as stock mentions, and tickers with a dot, such as BRK.B, are now recognised.
2026-10-31
ProspectAI Module

v1.11.0

  • Every number and grade in a report is now computed from live data. The AI model only writes the commentary and chooses each stock's action.
  • Stocks whose fundamentals can't be graded are marked unavailable and can only be Monitor or Avoid.
  • A slow Reddit lookup no longer stalls a run.
  • The technical score and overall fundamental grade fields were removed from reports.
2026-10-30
ProspectAI Module

v1.10.1

  • Fixed an issue where the market, technical and fundamental analysis steps could skip fetching live data and answer from the model alone. They now always fetch their data first.
2026-10-30
ProspectAI Module

v1.10.0

  • Analyses now run on Claude Haiku 5.5, Anthropic's latest model.
  • If a data-gathering step finishes without actually fetching its data, the analysis now stops with a clear error instead of reporting figures the model made up.
